# Agenda
- Static
  - Phương thức static là phương thức thuộc về class (thuộc về class thì không cần khởi tạo đối tượng)
  - khi nào cần sử dụng static? khi mà cái hàm đấy không phải là riêng biệt cho từng Object
  - Property belong to instance (property thuộc về instance)
  - Static belong to class
  - Saving memory
  - Có 2 loại static
    + Static method
    + Static property
    
- Final
  - Final đi với biến hoặc thuộc tính mục đích của nó là không cho phép thay đổi giá trị
  - Nếu final đi với class thì không thể kế thừa
  - Final đi với phương thức thì không thể ghi đè
