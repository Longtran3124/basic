# Agenda
- Constructor -> khởi tạo đối tượng
- Package -> sử dụng để dễ quản lý file
- Access Modifier -> phạm vi truy cập 
- OOP
- Assignments

- Access Modifier:
    - Class, Constructor, method, property
    - public (ở đâu cũng có thể truy cập được)
    - protecrd (Chỉ có thể truy cập khi cùng package)
    - default
    - private (Chỉ có thể dùng trong cùng class)

- Setter -> dùng để thiết lập giá trị 
- Getter 

- 4 Properties
  + Encapsulation (đóng gói) -> mục đích của đóng gói là bảo vệ dữ liệu, đảm bảo an toàn thông tin
    - Access modifier: Private
    - Getter/Setter

  + Inheritance (Kế thừa) -> các thuộc tính của lớp cha có khả năng cao lớp con sẽ được kế thừa
    - Keyword: Extend
    - Multi level inheritance
      + Direct superclass (1 level)
      + Indirect superclass (2 level)
      + Single inheritance
  + Abstraction (trìu tượng)
  + Polymorphism (tính đa hình)
