# Datatype - Kiểu dữ liệu
- Primitive (Kiểu dữ liệu nguyên thủy)
    + Interger (số nguyên):
      + byte
      + short
      + int 
      + long
  
    + Real number (số thực)
        + float
        + double
    
    + Characters (kí tự)
        + char
    + Boolean (true/false)
        + boolean

- Kiểu dữ liệu đối tượng:
    + String 
    + Date
    + Enum
    + Array

- Naming rules (Quy tắc đặt tên)
    + Thuộc tính là danh từ
    + Phải viết hoa từ bắt đầu ngoại trừ từ đầu tiên
    + Nếu kiểu dữ liệu là boolean thì phải có is ở phía trước
    + Enum phải viết hoa tất cả

- Object 
    + Property
    + Method 
- Init Object
