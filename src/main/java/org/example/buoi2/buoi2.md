# Agenda
- Flow Control Statement (Câu lệnh điều khiển luồng)
    + if-else:
        if(condition 1) {
            Task 1
        } else if(condition 2) {
            Task 2
        } else {
            Task 3
        }

    + Switch...case
        switch (variable) {
            case value 1:
                Task 1
                break;
            case value 2:
                Task 2
                break;
            default:
                default task
                break;
        }

    + for:
        for(init value; Condition; step) {
            statement
        }
    + for each:
        for(datatype : array) {
            statement
        }

    + while:
        while(condition) {
            statement
        }
    + do-while
        do {
            statement
        } while (mệnh đề điều kiện)

- break -> ngắt vòng lặp
- continue -> đi tiêp mà không chạy các dòng lệnh phía sau
- return
